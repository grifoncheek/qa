# Чек-листы

Я строил чек-листы по принципу «сначала критичное»: smoke, затем функциональные и граничные. Каждый пункт можно превратить в тест-кейс или баг-репорт.

## 1. UI — Swag Labs

### 1.1 Smoke (P1)

- [ ] SMK-01 Страница логина открывается, форма отображается корректно
- [ ] SMK-02 Вход standard_user / secret_sauce переводит в каталог
- [ ] SMK-03 Каталог содержит 6 товаров с названием, ценой и изображением
- [ ] SMK-04 Кнопка «Add to cart» кладёт товар в корзину
- [ ] SMK-05 Корзина открывается и показывает добавленный товар
- [ ] SMK-06 Оформление заказа проходится до сообщения «Thank you for your order!»
- [ ] SMK-07 Logout завершает сессию и возвращает на страницу логина

### 1.2 Функциональные (P1–P2)

- [ ] FUN-01 Вход locked_out_user даёт сообщение о блокировке
- [ ] FUN-02 Неверный пароль даёт сообщение о несовпадении логина и пароля
- [ ] FUN-03 Пустой логин даёт сообщение «Username is required»
- [ ] FUN-04 Пустой пароль даёт сообщение «Password is required»
- [ ] FUN-05 Поле пароля скрывает ввод
- [ ] FUN-06 Счётчик корзины отражает количество разных товаров
- [ ] FUN-07 Кнопка товара меняется на «Remove» после добавления
- [ ] FUN-08 Удаление товара из каталога уменьшает счётчик
- [ ] FUN-09 Удаление товара со страницы корзины убирает позицию из списка
- [ ] FUN-10 Сортировка Name (A to Z) сортирует по возрастанию имени
- [ ] FUN-11 Сортировка Name (Z to A) сортирует по убыванию имени
- [ ] FUN-12 Сортировка Price (low to high) сортирует по возрастанию цены
- [ ] FUN-13 Сортировка Price (high to low) сортирует по убыванию цены
- [ ] FUN-14 Итог Checkout: Item total равен сумме цен товаров
- [ ] FUN-15 Tax рассчитывается и входит в Total
- [ ] FUN-16 Checkout без First Name показывает ошибку и не пускает дальше
- [ ] FUN-17 Checkout без Last Name показывает ошибку
- [ ] FUN-18 Checkout без Postal Code показывает ошибку
- [ ] FUN-19 «Continue Shopping» возвращает в каталог с сохранённой корзиной
- [ ] FUN-20 «Reset App State» очищает корзину и счётчик

## 2. API — Restful-Booker

### 2.1 Smoke (P1)

- [ ] ASMK-01 GET /ping отвечает кодом 201
